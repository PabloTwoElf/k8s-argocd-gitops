# k8s-argocd-gitops
Despliegue GitOps con Argo CD y Kubernetes: Deployment, Service (NodePort) y HPA.
Tarea individual UDLA - Pablo Criollo Escobar.

- k8s/deployment.yml, k8s/service.yml, k8s/hpa.yml: manifiestos que Argo CD sincroniza.
- argocd/application.yml: Application de Argo CD (Automated Sync, prune y selfHeal).
- evidencias/: salidas de consola de la ejecucion.
